PAINEL DO BLOG (Sveltia CMS)

Guia completo: GUIA-PAINEL-BLOG.md

Resumo:
- Acesso: /admin/blog  (ou /admin)
- Login: "Entrar com token de acesso" + token do GitHub com permissão
  Contents: Read and write no repositório do site.
  ("Entrar com GitHub" funciona depois de configurar o OAuth App — ver guia.)
- Versão do Sveltia fixa com integrity: para atualizar, ver "Atualizar o Sveltia CMS" no guia.
- Artigos: src/content/posts/*.md  ·  Imagens: public/blog/
- Salvar = commit no GitHub → a Vercel publica sozinha.
- Status "Rascunho" não aparece no site; data futura = agendado.
